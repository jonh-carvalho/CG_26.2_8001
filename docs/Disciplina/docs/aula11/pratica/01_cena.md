### **Roteiro — Fase 1: Configuração Inicial**

#### **1. Objetivo**
Preparar o ambiente de trabalho e a cena base no Blender para estudar e visualizar os modelos de iluminação.

---

#### **2. Passo a Passo de Execução**

##### **1.1 Preparação da Cena**
1. **Criar nova cena:** Inicie um novo projeto limpo usando o comando **`Ctrl + N`**.
2. **Adicionar objetos base:**
   * Adicione um **Plano** para servir de superfície/chão.
   * Adicione uma **Esfera** e um **Cubo** como objetos de teste.
3. **Iluminação inicial:** Configure uma **luz solar básica** (*Sun light*).
4. **Câmera:** Posicione a câmera em um ângulo e posição favoráveis para enquadrar os objetos.

##### **1.2 Interface Essencial**
1. **Shader Editor:** Abra uma nova janela e selecione o **Shader Editor** para a criação e edição dos nós de materiais.
2. **Modo Renderizado:** Altere o modo de exibição na janela 3D para **Viewport Shading → Rendered** para visualizar o efeito da luz em tempo real.
3. **Painel de Materiais:** Vá no painel lateral de propriedades e selecione **Properties → Material Properties**.

---

#### **3. Atalhos Úteis para esta Fase**
* **`Ctrl + N`**: Criar nova cena.
* **`Z`**: Abrir o menu radial de *Viewport Shading*.
* **`Shift + Z`**: Alternar rapidamente para a visão renderizada (*Rendered View*).
