# Transformações em Objetos 3D com Python no Blender

## Documentação Oficial

A API do Blender oferece operadores como `bpy.ops.transform.translate`, `rotate`, `resize` e `transform` para translações, rotações, escalas e matrizes de transformação em objetos 3D. Acesse a referência completa para scripts personalizados: https://docs.blender.org/api/current/bpy.ops.transform.html .
