## Opção A — Animação (Blender 4.5 LTS)

### Objetivo

Criar uma sequência animada de **10 a 20 segundos** da cena noturna, utilizando pelo menos três animações distintas: lâmpada, câmera e uma animação livre de sua escolha.

### Conceitos-chave

| Conceito | Definição |
|---|---|
| **Keyframe** | Quadro-chave que armazena o valor de uma propriedade em um instante de tempo |
| **Interpolação** | Cálculo dos valores intermediários entre dois keyframes (Linear, Bezier, Constante) |
| **Timeline** | Linha do tempo do Blender onde os keyframes são visualizados e ajustados |
| **Graph Editor** | Editor de curvas de animação que controla a aceleração e desaceleração entre keyframes |
| **FPS** | Quadros por segundo; use 24 fps para padrão cinematográfico |

---

### Instruções

#### A.1 — Configuração da Timeline

1. Acesse `Output Properties` e defina:
   - `Frame Rate`: 24 fps.
   - `Frame Start`: 1 | `Frame End`: 480 (equivale a 20 s a 24 fps).
2. Abra a **Timeline** na parte inferior do layout padrão.
3. Certifique-se de que a cena da AC05 está carregada com o abajur e todos os materiais.

---

#### A.2 — Animação 1: Lâmpada Piscando (guiado)

Simule o piscar de uma lâmpada antiga variando a `Energy` da `Luz_Abajur`.

1. Selecione `Luz_Abajur` e vá para `Object Data Properties` (ícone de lâmpada).
2. Posicione o cursor na **frame 1**:
   - Clique com o botão direito em `Power` → **Insert Keyframe** (`I`). Valor: 50 W.
3. Avance para a **frame 12** (0,5 s):
   - Altere `Power` para 35 W → Insert Keyframe.
4. Frame **24** (1 s): `Power` de volta a 50 W → Insert Keyframe.
5. Selecione os três keyframes na Timeline → `Ctrl + C` e `Ctrl + V` para repetir o ciclo ao longo de toda a animação.
6. No **Graph Editor**: selecione os keyframes e altere a interpolação para `Bezier` para suavizar o efeito.

---

#### A.3 — Animação 2: Movimento de Câmera (guiado)

Crie um zoom-in gradual e um leve arco lateral da câmera.

1. Selecione `Camera_Principal`.
2. Frame **1**: posição atual da câmera → pressione `I → Location Rotation` para inserir keyframe.
3. Frame **240** (10 s):
   - Mova a câmera levemente para frente (`G`, `Y`, valor negativo em relação ao alvo) — simula zoom-in.
   - Rotacione levemente no eixo Z (`R`, `Z`, 15) — cria um arco.
   - `I → Location Rotation` para inserir keyframe.
4. No Graph Editor: ajuste as curvas para `Bezier` e verifique se não há movimentos bruscos.
5. Use `Numpad 0` para pré-visualizar a animação pela câmera (`Space` para reproduzir).

---

#### A.4 — Animação 3: Animação Livre (proposta pelo aluno)

Escolha **um** dos objetos da cena e crie uma animação criativa:

- **Lápis rolando**: keyframes de `Rotation` em Z passando de 0° para 30° (frame 1 a 120).
- **Livro se abrindo**: no Edit Mode, crie um vértice de dobradiça e anime a tampa com `Rotation`.
- **Copo deslizando**: keyframes de `Location` em X com efeito de *overshoot* (interpolação Bounce no Graph Editor).
- **Sua ideia**: documente no relatório o que foi animado e por quê.

---

#### A.5 — Exportação do Vídeo

1. Acesse `Output Properties`:
   - `Output Path`: escolha uma pasta para salvar os frames.
   - `File Format`: `FFmpeg Video`.
   - `Encoding → Container`: `MPEG-4`.
   - `Encoding → Video Codec`: `H.264`.
   - `Quality`: `High`.
2. Resolução: **1280 × 720** (HD) para agilizar o render.
3. Engine de render: **EEVEE** (recomendado para animação de iniciantes).
4. `Render → Render Animation` (`Ctrl + F12`).
5. O vídeo será salvo no caminho definido.

### Entregáveis — Opção A

2. Vídeo `AC06_NomeSobrenome.mp4` exportado (10–20 s).
3. Relatório (1 página) contendo:
   - Descrição de cada animação (tipo de interpolação utilizada, duração, valores de keyframe).

   - Descrição da animação livre com justificativa da escolha.

## Opção B — Jogo Interativo (UPBGE)

### Objetivo

Converter a cena da AC05 em uma **experiência interativa em tempo real** usando o UPBGE, permitindo que o usuário navegue pela cena e interaja com os objetos.

### O que é o UPBGE?

O **UPBGE** (Uchronia Project Blender Game Engine) é um fork do Blender que adiciona um motor de jogos integrado com suporte a física em tempo real, Logic Bricks e scripting Python. É compatível com arquivos `.blend` do Blender e ideal para protótipos interativos rápidos.

> **Instalação**: baixe o UPBGE 0.3.x em [upbge.org](https://upbge.org) — é um executável separado do Blender 4.5 LTS. Abra o arquivo `AC05_NomeSobrenome.blend` diretamente pelo UPBGE.

---

### Instruções

#### B.1 — Preparação da Cena para UPBGE (guiado)

1. Abra `AC05_NomeSobrenome.blend` no UPBGE.
2. Acesse `Render Properties` e verifique se o engine está definido como **UPBGE**.
3. Para cada objeto estático (mesa, livro, copo, lápis, abajur):
   - `Object Properties → Physics → Physics Type`: defina como **Static**.
4. Configure a gravidade em `Scene Properties → Gravity`: `-9.8` no eixo Z.
5. Salve como `AC06_NomeSobrenome.blend`.

---

#### B.2 — Câmera Interativa com Logic Bricks (guiado)

Permita que o jogador rotacione a câmera ao redor da mesa usando as teclas de seta.

1. Selecione `Camera_Principal`.
2. Acesse a aba **Logic** no editor de propriedades.
3. Adicione um **Sensor** do tipo `Keyboard`:
   - Tecla: `Left Arrow`.
4. Adicione um **Controller** do tipo `And`.
5. Adicione um **Actuator** do tipo `Motion`:
   - `Rot Z`: `0.02` (rotação por frame).
6. Conecte: Sensor → Controller → Actuator.
7. Repita para `Right Arrow` com `Rot Z`: `-0.02`.
8. Adicione controle de `Up Arrow` e `Down Arrow` com `Rot X` para inclinar a câmera.
9. Pressione `P` para iniciar o modo jogo e testar a câmera.

---

#### B.3 — Interação com o Abajur (guiado)

Ao clicar na `Abajur_Cupula`, alterne a lâmpada entre ligada e desligada.

1. Selecione `Abajur_Cupula`.
2. Adicione um **Sensor** do tipo `Mouse → Left Button`.
3. Adicione um **Controller** do tipo `Python` com o seguinte script:

```python
import bge

def toggle_light(cont):
    scene = bge.logic.getCurrentScene()
    luz = scene.objects.get("Luz_Abajur")
    if luz:
        luz.visible = not luz.visible
```

4. Adicione o script acima em um novo arquivo Python dentro do Blender (`Text Editor → New`), nomeie como `toggle.py`.
5. No Controller Python, referencie `toggle.py` na função `toggle_light`.
6. Teste com `P`: clicar na cúpula deve apagar e acender a lâmpada.

---

#### B.4 — Animação Simples com Action Actuator

Adicione uma animação sutil ao lápis (ex.: rotação contínua) para demonstrar o uso de ações no UPBGE.

1. No Blender 4.5 LTS (antes de abrir no UPBGE), crie uma **Action** de rotação do lápis:
   - Selecione `Lapis`.
   - Frame 1: `I → Rotation`.
   - Frame 60: rotacione 360° em Z (`R`, `Z`, `360`) → `I → Rotation`.
   - Salve a Action com o nome `Lapis_Rot`.
2. No UPBGE, selecione `Lapis`:
   - Sensor: `Always`.
   - Controller: `And`.
   - Actuator: `Action → Lapis_Rot`, `Play Mode: Loop`.
3. Teste com `P`: o lápis deve girar continuamente.

---

#### B.5 — Script Python de HUD Simples (opcional / desafio)

Exiba um texto na tela indicando o estado da lâmpada.

```python
import bge

def hud(cont):
    scene = bge.logic.getCurrentScene()
    luz = scene.objects.get("Luz_Abajur")
    if luz:
        estado = "LIGADA" if luz.visible else "DESLIGADA"
        print(f"Lâmpada: {estado}")  # use Text Object para exibição visual
```

> Para exibição visual, adicione um objeto do tipo **Text** à cena e atualize sua propriedade via Python: `obj_texto["Text"] = estado`.
