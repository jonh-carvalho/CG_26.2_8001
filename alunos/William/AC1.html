Fundamentos da Computação Visual

Objetivo: Demonstrar as diferenças e principais características das áreas: Síntese de Imagens, Processamento de Imagens, Visão Computacional e Visualização Computacional.

Modelo ➔ Imagem

1. Síntese de Imagens (Computação Gráfica)

Conceito: A partir de descrições matemáticas, geométricas ou de dados abstratos, o computador gera (sintetiza) uma imagem do zero. Envolve o cálculo de perspetiva, iluminação, sombras e rasterização.

Aplicação Demonstrada:

Renderização de uma geometria complexa (Torus Knot) num espaço tridimensional. O código define os vértices matematicamente e a biblioteca Three.js encarrega-se de projetar estes dados num ecrã 2D, aplicando um material básico com estrutura de arame (wireframe).

Imagem ➔ Imagem

2. Processamento de Imagens

Conceito: Recebe uma imagem como entrada e aplica transformações matemáticas aos seus píxeis para gerar uma nova imagem como saída. O objetivo é melhorar a qualidade visual, realçar características (como bordas) ou alterar o esquema de cores, sem interpretar semanticamente o conteúdo.

Aplicação Demonstrada:

Manipulação direta da matriz de píxeis de uma imagem gerada no Canvas HTML5. O código lê os valores RGB de cada píxel, aplica uma fórmula matemática e devolve a imagem reescrita.

Imagem ➔ Informação

3. Visão Computacional (Artificial)

Conceito: Procura extrair dados, significado ou decisões a partir de imagens. Ao contrário do processamento, aqui o computador "entende" o que está a ver através de algoritmos de inteligência artificial e reconhecimento de padrões.

Aplicação Demonstrada:

Detecção de múltiplos objetos numa imagem utilizando o modelo pré-treinado COCO-SSD executado via TensorFlow.js. Agora você pode fazer o upload da sua própria imagem e solicitar a identificação manualmente.

Dados ➔ Gráfico

4. Visualização Computacional

Conceito: Transforma grandes volumes de dados complexos, abstratos ou numéricos em representações visuais interativas (gráficos, mapas de calor, dashboards). Facilita a compreensão e a tomada de decisão por parte de utilizadores humanos, aproveitando a capacidade visual do nosso cérebro.

Aplicação Demonstrada:

Criação de um Gráfico Polar de Área (Polar Area Chart) utilizando a biblioteca Chart.js. Os dados de entrada são um ficheiro JSON abstrato (por exemplo, pontos de performance de um sistema em diferentes categorias). A biblioteca encarrega-se de mapear estes números exatos em áreas proporcionais e cores.

Passe o mouse sobre as áreas do gráfico para interagir com os dados brutos subjacentes.
