# Avaliação Continuada 01

## Atividade

### Objetivo

Demonstrar as diferenças e principais características das áreas relacionadas a Computação Visual: Síntese de Imagens (Computação Gráfica), Processamento de Imagens, Visão Computacional (Artificial) e Visualização Computacional.

### Considerações adicionais

Para cada uma das áreas deve-se selecionar uma aplicação, apresentar os principais aspectos e executar a aplicação ou código disponível em repositórios públicos com a devida explicação de aspectos específicos de cada área.

---

## 1. Síntese de Imagens (Computação Gráfica)

### Descrição

A Síntese de Imagens, também conhecida como Computação Gráfica, é a área responsável por gerar imagens artificiais a partir de modelos matemáticos. Nessa área, o computador cria objetos, cenários e animações sem depender de imagens reais como entrada.

### Para que serve

- Criar ambientes virtuais e simulações  
- Desenvolver jogos e animações  
- Gerar imagens realistas ou estilizadas  

### Principais aspectos

- Modelagem geométrica (vértices, polígonos)  
- Iluminação e sombreamento  
- Texturização  
- Transformações (rotação, escala, translação)  

### Exemplo de aplicação

Renderização de um cubo 3D rotacionando na tela.

### Aplicações no mundo real

- Jogos digitais  
- Filmes de animação  
- Realidade virtual e aumentada  
- Simuladores de treinamento  

---

## 2. Processamento de Imagens

### Descrição

O Processamento de Imagens consiste na manipulação de imagens digitais com o objetivo de melhorar sua qualidade ou prepará-las para análises posteriores. A entrada e a saída são imagens.

### Para que serve

- Melhorar qualidade de imagens  
- Reduzir ruídos  
- Destacar características importantes  

### Principais aspectos

- Operações com pixels  
- Filtros (blur, sharpen)  
- Transformações (escala de cinza)  
- Convolução  

### Exemplo de aplicação

Aplicação de um filtro de detecção de bordas (Canny).

### Aplicações no mundo real

- Edição de imagens  
- Câmeras digitais  
- Imagens médicas  
- Sistemas de segurança  

---

## 3. Visão Computacional

### Descrição

A Visão Computacional permite que o computador interprete e compreenda imagens ou vídeos, simulando a visão humana. Diferente do processamento de imagens, aqui há extração de significado.

### Para que serve

- Reconhecer objetos e pessoas  
- Identificar padrões  
- Automatizar decisões baseadas em imagens  

### Principais aspectos

- Machine Learning  
- Deep Learning  
- Extração de características  
- Classificação e detecção  

### Exemplo de aplicação

Detecção de rostos em imagens utilizando algoritmos como Haar Cascade.

### Aplicações no mundo real

- Reconhecimento facial  
- Carros autônomos  
- Diagnóstico médico  
- Sistemas de vigilância  

---

## 4. Visualização Computacional

### Descrição

A Visualização Computacional transforma dados em representações visuais, facilitando a compreensão de informações complexas.

### Para que serve

- Analisar grandes volumes de dados  
- Identificar padrões e tendências  
- Apoiar a tomada de decisão  

### Principais aspectos

- Representação gráfica de dados  
- Interatividade  
- Design visual  
- Exploração de dados  

### Exemplo de aplicação

Criação de gráficos interativos utilizando bibliotecas como Matplotlib ou Plotly.

### Aplicações no mundo real

- Dashboards empresariais  
- Análise de dados científicos  
- Monitoramento de indicadores  
- Visualização de dados públicos  

---

## Comparação entre as áreas

| Área | Entrada | Saída | Objetivo |
|------|--------|------|---------|
| Computação Gráfica | Dados | Imagem | Criar imagens |
| Processamento de Imagens | Imagem | Imagem | Modificar imagens |
| Visão Computacional | Imagem | Informação | Interpretar imagens |
| Visualização Computacional | Dados | Imagem | Representar dados |

---

## Conclusão

As áreas de Computação Visual possuem objetivos distintos, mas complementares. Enquanto a Computação Gráfica cria imagens, o Processamento de Imagens as modifica, a Visão Computacional interpreta seu conteúdo e a Visualização Computacional transforma dados em representações visuais compreensíveis. Essas áreas são fundamentais em diversas aplicações modernas, desde entretenimento até ciência e indústria.
