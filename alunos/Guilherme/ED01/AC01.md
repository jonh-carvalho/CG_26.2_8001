# 1. Síntese de Imagens (Computação Gráfica)

A Síntese de Imagens, também conhecida como Computação Gráfica, é a área responsável por gerar imagens a partir de modelos matemáticos ou geométricos, geralmente representando objetos em duas ou três dimensões.

Essa área envolve técnicas como:
- Modelagem de objetos
- Aplicação de texturas
- Iluminação
- Renderização
- Animação

O objetivo principal é produzir imagens realistas ou estilizadas que representem objetos ou ambientes virtuais.

Diferentemente de outras áreas da computação visual, na síntese de imagens a imagem não existe previamente, sendo criada a partir de dados e algoritmos.

## Aplicação Utilizada

Esse projeto implementa um ray tracer simples em C++, utilizado para demonstrar a geração de imagens a partir de uma cena definida matematicamente.

## Funcionamento da Aplicação

O Ray Tracing é uma técnica de síntese de imagens que simula o comportamento da luz para gerar imagens a partir de uma cena tridimensional.

De forma simplificada, o algoritmo projeta raios a partir da câmera para cada pixel da imagem e verifica se eles interceptam objetos presentes na cena. Quando ocorre uma interseção, a cor do pixel é calculada considerando fatores como iluminação e propriedades do material. Caso o raio não atinja nenhum objeto, o pixel recebe a cor de fundo.

Na aplicação utilizada, implementada em C++, o programa calcula a cor de todos os pixels e grava os valores em um arquivo no formato PPM (Portable Pixmap). Esse arquivo armazena a resolução da imagem e os valores RGB de cada pixel, podendo posteriormente ser aberto diretamente ou convertido para formatos mais comuns, como PNG ou JPEG, permitindo visualizar a imagem gerada.

# 2. Processamento de Imagens

O Processamento de Imagens consiste na aplicação de algoritmos para modificar, transformar ou melhorar imagens já existentes.

Diferentemente da síntese de imagens, onde a imagem é criada do zero, aqui a imagem já existe e será transformada por meio de operações computacionais.

Entre as principais técnicas utilizadas estão:

- Filtragem de ruído
- Ajuste de contraste
- Segmentação de imagens
- Compressão
- Detecção de bordas

O objetivo pode ser melhorar a qualidade da imagem ou preparar os dados para etapas posteriores de análise.

# 3. Visão Computacional

A Visão Computacional é uma subárea da inteligência artificial dedicada ao desenvolvimento de métodos que permitem que computadores interpretem e compreendam informações visuais provenientes de imagens ou vídeos.

O objetivo é extrair informações semânticas do conteúdo visual.

Para isso, são utilizadas técnicas como:

- Aprendizado de máquina
- Redes neurais convolucionais (CNN)
- Reconhecimento de padrões

Aplicações comuns incluem:

- Reconhecimento facial
- Detecção de objetos
- Classificação de imagens
- Análise de expressões faciais

# 4. Visualização Computacional

A Visualização Computacional tem como objetivo transformar grandes volumes de dados em representações visuais compreensíveis.

Essas representações podem incluir:

- Gráficos
- Mapas
- Dashboards
- Visualizações interativas

Essa área é amplamente utilizada em:

- Ciência de dados
- Análise exploratória de dados
- Business intelligence

O objetivo principal é facilitar a interpretação e comunicação de informações complexas.
